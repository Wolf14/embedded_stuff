    .thumb_set EXTI15_10_IRQHandler, Default_Handler

    problem is that it set the symbol: EXTI15_10_IRQHandler = Default_Handler
    Tis happens even if you have defined the function EXTI15_10_IRQHandler elsewhere in C

    The correct way to handle is to instead write a stub function:
        .weak EXTI15_10_IRQHandler
        .type EXTI15_10_IRQHandler, %function
        EXTI15_10_IRQHandler:
            bl Default_Handler
            b .
